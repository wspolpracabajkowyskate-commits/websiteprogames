What is a boxing arcade machine?

A boxing arcade machine is an amusement game in which a player strikes a punching bag and receives a displayed score. “Boxer machine” is another name used for this type of arcade attraction.

How does the game work?

The player starts a game using the machine’s configured start or payment system, strikes the bag and reads the score. The exact sequence, scoring behaviour and available modes depend on the model. Follow the instructions provided with the machine.

A score is a game result. Do not treat it as a medical measurement or a calibrated comparison between different machine models without documentation establishing that use.

Dedicated boxer or combination machine?

A dedicated boxer focuses on punching. Combination machines add other challenges: the PRO-GAMES Double Hit combines boxing and kicking, while Monster 3 in 1 includes boxing, kicking and a hammer game.

What makes a machine suitable for your venue?

Look beyond cabinet artwork. Compare published dimensions, game format, payment options, service arrangements and installation requirements for the exact machine. Confirm the intended player group when considering kids models.
