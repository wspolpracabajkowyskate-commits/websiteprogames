# PRO GAMES CREATOR

Paczka zawiera stronę v25 i nowy, odizolowany folder progames/creator.

Jeżeli masz już wdrożoną v25: skopiuj tylko folder creator do katalogu głównego strony. Otwórz /creator/ lub /creator/index.html. Nie trzeba instalować żadnych narzędzi do korzystania z gotowego konfiguratora.

Model: progames/creator/assets/double-strike.glb
Instrukcja i ograniczenia: progames/creator/README-PL.md
Źródła i generator modelu: progames/creator/source/
Raport testów: progames/creator/docs/

Nie jest to model CAD ani pomiar rzeczywistej maszyny. Wymiary i montaż opcjonalnych modułów są orientacyjne. Przed wdrożeniem produkcyjnym wymagane są potwierdzenie modelu oraz testy płynności na fizycznych urządzeniach.
