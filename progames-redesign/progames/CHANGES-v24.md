# v24 — dopracowanie karty produktu

- Przywrócone poziome przewijanie kolorów na telefonach.
- Liczba kolumn parametrów odpowiada liczbie rzeczywistych kart; sekcja zajmuje pełną szerokość.
- Karty parametrów mają naturalną wysokość, bez rozciągania pustego wnętrza.
- Elastyczna wysokość zdjęcia równoważy kolumnę konfiguratora; opis i katalog mają mniejsze odstępy.
- Jeden przycisk zapytania i dotychczasowe opcje pozostają zachowane.
- Wersja zasobów 24.

Weryfikacja: build 96 stron, testy publikacji 90 kart; przeglądarka 390/768/1440 px, 3 modele; brak poziomego przepełnienia, pełna szerokość parametrów, przewijanie i wybór ostatniego koloru. Test konfiguracji EN/ES i przekazania danych do formularza zakończony poprawnie. Formularz nadal korzysta z programu pocztowego przez mailto.
